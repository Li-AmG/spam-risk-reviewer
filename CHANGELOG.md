## v0.1.0 - 2026-09-21

Initial public demo.

- Published a static browser-only demo on Cloudflare Workers.
- Added five synthetic campaign scenarios: opt-in newsletter, product launch, wording review, reactivation list, and imported promo blast.
- Added pass, review, and hold outcomes with plain-English review notes.
- Added copyable review summaries and downloadable JSON reports.
- Added scenario tests for the built-in examples and rule behavior.
- Added a compact how-it-works section explaining local input mapping, rule checks, and output.
- Added visible policy presets: Conservative, Standard, and Lenient.
- Added README, roadmap, contribution notes, privacy notes, MIT license, issue templates, and launch materials.

This release is an early advisory checklist. It does not verify DNS, send email, predict inbox placement, or grant permission to send.
