# License Notes

The demo is currently licensed under MIT.

MIT was selected because this project is an early browser-only demo intended for low-friction sharing, reuse, and feedback.

## Common Choices

### MIT

Simple and permissive. It allows reuse, modification, distribution, and commercial use with attribution and warranty disclaimer.

Good fit when the goal is broad adoption and low friction.

### Apache-2.0

Permissive like MIT, with an explicit patent grant and more detailed terms.

Good fit when patent clarity matters or when the project may attract company contributors.

### GPL-3.0

Copyleft. Modified versions distributed to others generally need to keep the same license.

Good fit when the maintainer wants downstream changes to remain open under similar terms.

### Source-Available / No License Yet

People can read the code, but reuse rights are not granted by default.

Good fit while ownership, goals, and contribution policy are still being decided.

## Practical Recommendation

Keep MIT unless the project later needs a stronger patent posture or a copyleft contribution model. If that changes, update `LICENSE`, `README.md`, `CONTRIBUTING.md`, and launch materials together.
